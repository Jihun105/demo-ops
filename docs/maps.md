# 카카오 지도와 KML 묘지 좌표

PC와 휴대폰의 묘지 지도는 공용 Kakao Maps Web API 프레임을 사용합니다. 묘지 위치는 기존 Google Earth KML/KMZ에서 확인해 저장한 좌표를 그대로 사용합니다. 승인된 현장 GPS가 있으면 기존 우선순위를 유지합니다. 현재 묘지 주소와 저장 당시 주소가 다르면 기존 좌표를 적용하지 않습니다.

주소를 다시 검색해 묘지 위치를 추정하지 않습니다. 저장된 좌표가 없거나 유효하지 않으면 **좌표 확인 필요**로 표시하며 KML 가져오기 또는 PC의 위치 보정으로 확인합니다. Google 주소 검색의 임시 좌표는 카카오 지도나 작업 순서 계산에 전달하지 않습니다. 기존 임시 캐시는 기존 만료 정리 대상으로 남고 새 Google 주소 조회는 실행하지 않습니다.

PC 묘지 지도의 **스카이뷰**는 글씨·도로 안내를 제외한 위성사진에 시별 경계선과 묘지 핀만 표시합니다. 위성사진 위의 경계 면 채우기는 제거하며, **지도** 버튼으로 일반 지도에 돌아갈 수 있습니다. 카카오 로고·영상 출처·축척·지도 조작 버튼은 유지합니다.

## 카카오 키 설정

1. 프로젝트 루트의 `.env`를 엽니다. 새 환경에서는 `.env.example`을 `.env`로 복사합니다. 실제 값은 Git 제외 대상인 `.env`에서만 관리합니다.
2. `KAKAO_MAPS_JAVASCRIPT_KEY`에 지도 표시용 JavaScript 키를 넣고 카카오 개발자 콘솔에서 Web 지도 사용 및 사이트를 등록합니다. PC는 `http://127.0.0.1:8092`, 모바일 앱은 현재 WebView origin인 `https://localhost`를 등록합니다. 미리보기는 실제 사용하는 loopback origin도 등록합니다.
3. `KAKAO_MOBILITY_REST_API_KEY`에 카카오모빌리티 자동차 길찾기에 사용할 REST API 키를 넣고 해당 서비스의 사용 권한·한도를 확인합니다. 이 키는 PC 메인 프로세스에서만 사용하고 지도 iframe이나 모바일 번들에는 넣지 않습니다.
4. PC 실행과 모바일 빌드가 프로젝트 루트의 `.env`를 자동으로 읽습니다. 셸에서 지정한 환경변수는 `.env`보다 우선합니다. 모바일에 별도 지도 키를 쓰려면 `DEMO_MOBILE_KAKAO_MAPS_JAVASCRIPT_KEY`에 설정합니다. 비어 있으면 `KAKAO_MAPS_JAVASCRIPT_KEY`를 공용으로 사용합니다.
5. PC를 재시작하고 휴대폰은 빌드·동기화 후 앱을 다시 설치합니다. 키 파일을 만들었다는 사실만으로 카카오 계정의 서비스 활성화나 실제 API 연결이 검증되지는 않습니다.

이전 `config/*-maps.cjs`는 더 이상 읽지 않습니다. 기존 Google 키·지도 ID는 `.env`로 이전했으며 시작 묘지 선택 지도에서 사용합니다. KML 원본·좌표·면적 자료를 삭제하거나 다시 가져올 필요는 없습니다. 전체 설정 목록은 [환경 설정](environment.md)을 참고하세요.

## 작업 순서

**작업 관리 → 작업 순서 설정 → 지역 복수 선택 → 시작 묘지 선택 → 순서 만들기**로 사용합니다. 진행 상태의 작업만 포함하며 선택 지역을 하나로 합쳐 계산합니다. 시작 묘지는 1번이고 마지막 묘지에서 종료합니다.

시작 묘지 찾기의 **선택 지역 지도 보기**를 누르면 선택한 지역의 진행 작업에 저장된 KML·승인 좌표 핀이 구글 지도에 표시됩니다. 시작점 선택 지도는 `.env`의 기존 `GOOGLE_MAPS_API_KEY`, `GOOGLE_MAP_ID`를 사용하고 방문 순서의 이동시간은 카카오로 계산합니다. 핀을 더블클릭하면 시작 묘지로 선택되고 검색 목록에도 반영됩니다. 한 번 클릭하면 성함·주소를 확인할 수 있습니다. 같은 위치에 작업이 여러 개면 나타나는 목록에서 시작할 묘지를 고릅니다. 저장 좌표가 없는 작업은 **좌표 확인 필요** 목록으로 표시합니다. 지도 조회는 이동시간 계산이나 작업 순서 저장을 실행하지 않습니다.

카카오모빌리티 자동차 길찾기 API의 `TIME` 옵션으로 방향별 이동시간을 조회하고 앱에서 전체 방문 순서를 개선합니다. 조회 시점의 교통 기준 추천 순서이며 수학적 최적이나 나중의 실제 내비 시간과 일치함을 보장하지 않습니다. 묘지까지의 도보·작업 시간과 시작점 복귀는 포함하지 않습니다.

30개 위치를 전부 비교하면 최대 870개 방향 구간을 조회합니다. 같은 좌표의 작업은 조회를 재사용하되 표의 작업 행은 각각 유지합니다. 실행 전에 조회 수 상한을 표시하고 진행 중 취소할 수 있습니다. 위치·경로가 확인되지 않으면 해당 작업을 알려주고 불완전한 계획을 저장하지 않습니다.

작업 확인에 `부천/시흥` 같은 시트가 생깁니다. 순서와 작업 ID만 보관하며 이동시간 행렬·도로 형상·전체 API 응답은 보관하지 않습니다. 계산 직후 예상 이동시간을 보여주고, 재실행 후 최신 시간이 필요하면 다시 계산합니다. 시트를 만든 뒤 새로 진행된 작업은 **추가 대기**로 표시되어 번호를 정해 끼워 넣고, 삭제·진행 취소된 작업은 자동으로 빠집니다. 주소·위치나 문자·입금·금액만 바뀌면 방문 순서를 유지합니다. 자세한 흐름은 [사용 안내](usage.md#시트에-작업-끼워-넣기-추가-대기)를 참고하세요. 현장 길안내나 내비 앱 실행은 추가하지 않습니다.

공유 모드는 `20261018-work-routes` 서버 업데이트가 필요하며 로컬 모드는 해당 고객 DB 안에 별도 계획 표를 저장합니다. 서버 SQL은 [SQL 적용 안내](sql-application.md)에 따라 준비·검증합니다. 구형 서버에서도 기존 작업 관리/확인은 계속 사용하고 순서 기능에서 업데이트를 안내합니다.

## 좌표와 원본 보관

현장·공공 좌표의 기존 `.demo-map` 저장과 KML/KMZ 원본 보관·회사 공유 구조를 유지합니다. 카카오 지도 타일·위성사진·길찾기 응답을 회사 저장소에 복사하지 않습니다. 원본 보관은 [데이터 관리](data.md), 지역 경계는 [경계 출처](reference/map-boundaries.md)를 참고하세요.

공식 문서: [Kakao Maps Web](https://apis.map.kakao.com/web/guide/), [카카오모빌리티 자동차 길찾기](https://developers.kakaomobility.com/guide/navi-api/directions).

## 현장 좌표 수정 요청 (2026-10-27 삭제)

휴대폰의 좌표 수정 요청과 PC 묘지 지도의 좌표 승인 대기 탭은 쓰지 않아 PC 0.2.2·휴대폰 1.7.1에서 지웠습니다. 휴대폰 앱은 더 이상 위치 권한을 요청하지 않습니다. 이미 승인돼 `source: field`로 저장된 좌표는 그대로 씁니다. 서버의 `demo_location_requests` 표와 관련 함수·트리거는 다음 서버 배포판에서 정리합니다.

## 데스크톱 지도 별도 창

지도 위쪽 한 줄에 **지역 선택**과 선택한 지역, 오른쪽 끝에 검색창이 있습니다. 건수 문구는 표시하지 않습니다. 검색창에서 지역·고객명·전화번호·주소를 함께 검색합니다. 전화번호의 공백과 하이픈은 무시하며, 검색은 불러온 고객 자료 안에서 처리합니다. **지역 선택**을 누르면 지역 검색창과 휠로 스크롤하는 다중 선택 목록이 열리고, 선택한 지역만 옆에 해제 가능한 버튼으로 표시됩니다. 선택이 없으면 전체 지역입니다. 검색과 지역 선택을 함께 사용하면 선택 지역 안에서 검색합니다. 결과를 누르면 고객 상세와 지도 위치를 보여주며, 좌표가 없는 결과는 위치 확인 필요로 표시합니다.

묘지 지도 하단 오른쪽의 **새 창으로 보기**로 지도를 별도 창에 엽니다. 별도 창은 검색창·지역 선택·지도 중심으로 표시하며, 주소 확인 목록·하단 도구는 표시하지 않습니다. 핀 상세 조회는 유지합니다. 다른 업무 화면으로 이동해도 지도 창은 유지되며, 이동·크기 조절·최대화할 수 있습니다. 처음에는 선택한 지역과 고객을 넘기고, 다시 누르면 기존 창을 앞으로 가져와 위치와 확대 상태를 유지합니다. 고객 저장과 좌표 공유 결과는 두 지도에 반영합니다. 로그아웃, DB 변경, 메인 창 종료 시 별도 지도 창도 닫습니다. 추가 창은 기존 좌표 캐시와 조회 대기열을 공유하며 별도의 전체 주소 재조회나 공유 채널을 만들지 않습니다. 지도 화면을 추가로 띄우는 카카오 지도 로드는 발생할 수 있습니다.
